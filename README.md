# ☕ Starbucks Sales Dashboard | Power BI

An interactive Power BI dashboard built to analyze Starbucks sales performance, customer behavior, and operational efficiency using DAX, Power Query, and data modeling.

---

## 📌 Project Overview

This dashboard provides business insights from over **100,000 Starbucks transactions** across multiple store locations, order channels, customer demographics, and time periods.

The report helps identify sales trends, customer preferences, operational performance, and revenue growth through interactive visualizations.

## 💡 Business Insights

- Morning hours generate the highest number of orders.
- Mobile App is the leading order channel.
- Suburban stores generate the highest revenue.
- Repeat customers account for a significant portion of total customers.
- Customer satisfaction remains consistent across both years.
